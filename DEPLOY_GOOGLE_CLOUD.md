## Крок 1: Створення проекту в Google Cloud Console

1. Відкрийте браузер і перейдіть у [Google Cloud Console](https://console.cloud.google.com/).
2. У верхньому лівому кутку біля логотипу Google Cloud натисніть на меню вибору проекту -> **«New Project»** (Новий проект).
3. Введіть ім'я проекту: наприклад `ghostboard-prod` та натисніть **«Create»**.
4. Переконайтеся, що проект прив'язаний до вашого **Billing Account** (Платіжного акаунту) з $300 кредитами:
   * Зліва в меню відкрийте **Billing** (Оплата) та перевірте наявність зеленого статусу з балансом промо-кредитів.

## Крок 2: Створення бази даних PostgreSQL

Ghostboard зберігає історію сесій, користувачів та 3D Скоркарди в базі даних PostgreSQL.

### Варіант А: Створити базу на Google Cloud SQL (списується з $300 балансу)
1. У лівому меню GCP знайдіть **SQL** (або введіть у пошук `Cloud SQL`).
2. Натисніть **«Create Instance»** -> виберіть **PostgreSQL**.
3. Заповніть налаштування:
   * **Instance ID:** `ghostboard-db`
   * **Password:** Придумайте надійний пароль для користувача `postgres` (збережіть його!).
   * **Database version:** `PostgreSQL 16`
   * **Configuration preset:** Оберіть **Sandbox / Development** (найекономніший тариф, щоб не витрачати зайві кредити).
   * **Region:** Виберіть `europe-west1` (Бельгія) або `europe-west3` (Франкфурт) — найближче до України.
   * **Machine configuration:** `Shared core` -> `1 shared vCPU, 0.614 GB RAM` (достатньо для старту).
4. Натисніть **«Create Instance»** (створення триває ~3-5 хвилин).
5. Після створення перейдіть у вкладку **Databases** -> **Create Database** -> введіть назву `ghostboard`.
6. У вкладці **Connections** -> **Networking** додайте публічний доступ або авторизовану мережу, або використовуйте Cloud SQL Auth Proxy.
7. Ваш підсумковий `DATABASE_URL` матиме вигляд:
   ```env
   DATABASE_URL="postgresql://postgres:ВАШ_ПАРОЛЬ@ПУБЛІЧНИЙ_IP_БАЗИ:5432/ghostboard?sslmode=disable"
   ```

> 💡 **Порада-лайфхак:** Якщо ви хочете зберегти всі $300 суто на Cloud Run та Gemini, базу даних можна за 1 хвилину створити на [Neon.tech](https://neon.tech) безкоштовно. Вона дає безкоштовний пожиттєвий PostgreSQL без жодної копійки витрат.

## Крок 3: Деплой на Google Cloud Run

У нашому проекті вже налаштовано оптимізований multi-stage **`Dockerfile`** та файл **`next.config.ts`** з прапорцем `output: 'standalone'`. Контейнер збирається у легкому Alpine Linux і важить менше 130 МБ!

### Спосіб 1: Найпростіший через GitHub (Автодеплой при кожному коміті)
1. Завантажте ваш код у приватний репозиторій на **GitHub**:
   ```bash
   git init
   git add .
   git commit -m "feat: ready for cloud run deployment"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГІН/ghostboard.git
   git push -u origin main
   ```
2. У Google Cloud Console введіть у пошуковий рядок **Cloud Run** -> натисніть **«Create Service»**.
3. У блоці налаштувань оберіть:
   * **«Continuously deploy from a repository»** (Натисніть **Set up with Cloud Build**).
   * Авторизуйте свій GitHub-акаунт та оберіть репозиторій `ghostboard`, гілку `main`.
   * **Build Type:** виберіть **Dockerfile** (шлях залишіть за замовчуванням `/Dockerfile`).
4. **Service name:** `ghostboard-app`.
5. **Region:** оберіть `europe-west1` (Бельгія) або `europe-west3` (Франкфурт).
6. **Authentication:** обов'язково поставте позначку **«Allow unauthenticated invocations»** (щоб ваш сайт могли відкривати користувачі без входу в Google акаунт).
7. Натисніть **«Create»**!
8. Google за 2 хвилини автоматично збере Docker-образ і запустить сайт. Ви отримаєте готову робочу URL-адресу з безкоштовним HTTPS:
   `https://ghostboard-app-xxxxxx-ew.a.run.app`

---

### Спосіб 2: Через безкоштовний Cloud Shell (в 1 команду прямо у браузері)
Якщо ви не хочете підключати GitHub, можна скористатися вбудованим терміналом прямо в браузері:
1. У Google Cloud Console у правому верхньому кутку натисніть іконку **`[>_]` (Activate Cloud Shell)**.
2. Внизу відкриється безкоштовна Linux-машина від Google.
3. Завантажте туди проект або скопіюйте код.
4. Виконайте команду:
   ```bash
   gcloud run deploy ghostboard-app \
     --source . \
     --region europe-west1 \
     --allow-unauthenticated \
     --port 8080
   ```
5. Google запитає дозвіл на увімкнення Artifact Registry — натисніть `y` (Enter).
6. Через 90 секунд з'явиться готове посилання на ваш працюючий сайт!

Щоб сервіс мав доступ до Gemini, Deepgram та бази даних:

1. У консолі **Cloud Run** натисніть на ваш сервіс `ghostboard-app`.
2. Натисніть кнопку **«Edit & Deploy New Revision»** (Редагувати та розгорнути нову версію).
3. Перейдіть у вкладку **Variables & Secrets** (Змінні та секрети).

## Крок 5: Підключення власного домену та безкоштовний HTTPS

Коли ви захочете прикріпити свій гарний домен (наприклад `ghostboard.io` або `app.ghostboard.io`):

1. У меню **Cloud Run** у верхній панелі натисніть **«Manage Custom Domains»** (Керування власними доменами).
2. Натисніть **«Add Mapping»**:
   * Оберіть сервіс: `ghostboard-app`.
   * Вкажіть ваш домен: наприклад `app.ghostboard.io` або `ghostboard.io`.
3. Google покаже вам таблицю з DNS-записами:
   * Тип **CNAME** або **A / AAAA** записи.
4. Перейдіть до вашого реєстратора домену (Namecheap, Cloudflare, GoDaddy тощо) і додайте вказані записи у DNS-панелі.
5. **Все!** Google Cloud самостійно випустить сертифікат безпеки SSL (HTTPS) і буде автоматично продовжувати його щороку.

## Крок 6: Контроль бюджету та збереження балансу на 12+ місяців

Щоб ваші безкоштовні $300 не закінчилися раптово, налаштуйте автоматичні сповіщення:

1. У лівому меню GCP перейдіть у **Billing** -> **Budgets & alerts** (Бюджети та сповіщення).
2. Натисніть **«Create Budget»**:
   * **Amount:** Вкажіть цільову суму $300 (або $100 на місяць).
   * **Thresholds:** Поставте 50% ($150), 80% ($240), 95% ($285).
   * **Notifications:** Вкажіть ваш email.
3. Якщо витрати досягнуть ліміту, Google надішле вам сповіщення на пошту.
4. **Масштабування до нуля (Scale to Zero):**
   * За замовчуванням у Cloud Run встановлено `Minimum instances: 0`. Це означає, що коли сайт ніхто не відвідує, процесорні потужності повністю зупиняються і **гроші не списуються взагалі**! Коли заходить користувач, контейнер прокидається за 0.5 секунди.
